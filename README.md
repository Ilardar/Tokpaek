# Токпаёк (Tokpaek)

Круглый виджет квот для Claude, Codex и Antigravity — показывает остаток лимита и таймер сброса прямо поверх окна ИИ-инструмента, в котором вы работаете.

> Скриншоты устарели: виджет сменил форму с полоски на круг. Новые появятся в ближайшем релизе.

Виджет сам переключается на тот инструмент, который сейчас активен, и умеет показываться только пока открыто окно наблюдаемого приложения («Умный фокус»).

Поддерживаются три семейства:

- **Claude** — приложение Claude Desktop и Claude Code / CLI;
- **Codex** — приложение Codex/ChatGPT и Codex CLI;
- **Antigravity** — Antigravity 2.0, Antigravity IDE и CLI.

## Возможности

- **Круглая шкала** с двумя дугами: верхняя — скользящее окно (5 часов), нижняя — семь дней или пул Claude / GPT (переключается).
- **Таймер сброса** в центральной плашке: пять часов или семь дней на выбор, точное время и обратный отсчёт.
- **Палитры**: градиент (плавный переход зелёный → жёлтый → красный), светофор (третьи), бирюзовая, монохром.
- **Формат шкалы**: десятичная (10 ячеек), часовая (12 ячеек), сплошная дуга. Гладкая отрисовка при любом масштабе.
- **Умный фокус**: виджет виден, только пока открыто окно Antigravity, Claude или ChatGPT, и держится поверх окна этого приложения — другие окна могут его накрыть.
- **Поверх всех окон** — отдельная галка для тех, кому виджет нужен всегда наверху.
- **Ресайз мышью** за край круга, как у обычного окна; перетаскивание — за центр. Позиция и размер запоминаются.
- **Прозрачность** и **интервал опроса** — слайдеры с готовыми значениями.
- Без кнопки на панели задач: перетаскивание — ЛКМ, меню — ПКМ по виджету или иконка в трее.
- Проверка обновлений по тегу релиза на GitHub — только по запросу.

## Приватность

- **Нет телеметрии.** Ни аналитики, ни счётчиков, ни сбора статистики.
- **Нет рекламы.** Никаких баннеров, партнёрских ссылок и «предложений».
- **Нет серверов автора.** Программа обращается только к API самих сервисов (Anthropic, OpenAI) и к локальному языковому серверу Antigravity на 127.0.0.1.
- Токены читаются локально, из хранилищ уже установленных программ, и уходят только тому сервису, которому принадлежат. Токпаёк ничего не пишет в чужие файлы и не обновляет чужие токены.
- Единственный сетевой запрос — проверка новой версии на GitHub (только по запросу пользователя).
- Свои настройки Токпаёк хранит в `%APPDATA%\Tokpaek\settings.json`.

## Откуда берутся данные

| Инструмент | Источник |
|---|---|
| Claude | локальный токен Claude Desktop → официальный эндпоинт использования аккаунта |
| Codex | `~/.codex/auth.json` (общий у приложения и CLI) → эндпоинт использования Codex |
| Antigravity | локальный языковой сервер Antigravity — тот же запрос, что делает панель расхода в самой IDE |

Если инструмент не установлен или не запущен, его источник просто помечается как недоступный — остальные продолжают работать.

## Установка

Скачайте `Tokpaek-Setup.exe` со страницы [релизов](https://github.com/Ilardar/Tokpaek/releases) и запустите. Установка идёт в профиль пользователя, права администратора не нужны.

При установке можно сразу включить автозапуск; позже это переключается в настройках или в меню трея.

## Как пользоваться

- **ЛКМ по кругу** — перетащить; **ЛКМ по плашке** — переключить таймер (ПЯТЬ ЧАСОВ / СЕМЬ ДНЕЙ).
- **Край круга** — изменить размер перетаскиванием.
- **ПКМ по виджету** — меню: Обновить, Домой (в левый верхний угол), Показывать поверх всех окон, Настройки, Закрыть.
- **Иконка в трее** — то же меню. Настройки открываются по центру того монитора, где вы находитесь.

## Требования

- Windows 10/11, x64.
- Установленный инструмент, чью квоту нужно смотреть: Claude Desktop, Codex CLI/приложение, Antigravity.
- Для Antigravity — запущенное приложение или IDE (квота живёт в его языковом сервере).

## Сборка из исходников

```
cargo build --release
```

Инсталлятор (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

```
powershell -ExecutionPolicy Bypass -File tools\build-installer.ps1
```
