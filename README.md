# Токпаёк (Tokpaek)

[English](README.en.md) | **Русский**

Круглый виджет квот для Google Antigravity — показывает остаток лимита и таймер сброса прямо поверх окна IDE или приложения, в котором вы работаете.

| Сплошная дуга (5 часов) | Сплошная дуга (7 дней) | Шкала с делениями | Предупреждение о лимите |
| :---: | :---: | :---: | :---: |

| *Сброс 5ч-окна* | *Сброс недельного лимита* | *Режим ячеек / пула* | *Индикация исчерпания* |

Виджет умеет показываться только пока открыто рабочее окно («Умный фокус»), отслеживая приложения и окружение Antigravity:

- **Antigravity 2.0** — десктопное приложение Antigravity;
- **Antigravity IDE** — среда разработки и локальный языковой сервер;
- **Antigravity CLI** — консольный интерфейс.

## Возможности

- **Круглая шкала** с двумя дугами: верхняя — скользящее окно (5 часов), нижняя — недельный лимит (семь дней) или общий пул (переключается).
- **Таймер сброса** в центральной плашке: пять часов или семь дней на выбор, точное время и обратный отсчёт (переключается кликом по плашке).
- **Палитры**: градиент (плавный переход зелёный → жёлтый → красный), светофор (трети), бирюзовая, монохром.
- **Формат шкалы**: десятичная (10 ячеек), часовая (12 ячеек), сплошная дуга. Гладкая отрисовка при любом масштабе.
- **Умный фокус**: виджет виден, только пока открыто окно Antigravity (IDE или CLI), и держится поверх его окна — другие окна могут его накрыть.
- **Поверх всех окон** — отдельная галка для тех, кому виджет нужен всегда наверху.
- **Ресайз мышью** за край круга, как у обычного окна; перетаскивание — за центр. Позиция и размер запоминаются.
- **Прозрачность** и **интервал опроса** — слайдеры с готовыми значениями.
- Без кнопки на панели задач: перетаскивание — ЛКМ, меню — ПКМ по виджету или иконка в трее.
- Проверка обновлений по тегу релиза на GitHub — только по запросу.

## Приватность

- **Нет телеметрии.** Ни аналитики, ни счётчиков, ни сбора статистики.
- **Нет рекламы.** Никаких баннеров, партнёрских ссылок и «предложений».
- **Нет серверов автора.** Программа обращается исключительно к локальному языковому серверу Antigravity на 127.0.0.1.
- Данные запрашиваются локально из запущенного языкового сервера Antigravity. Токпаёк ничего не пишет в чужие файлы и не отправляет данные на внешние серверы.
- Единственный сетевой запрос — проверка новой версии на GitHub (только по запросу пользователя).
- Свои настройки Токпаёк хранит в `%APPDATA%\Tokpaek\settings.json`.

## Откуда берутся данные

| Инструмент | Источник |
|---|---|
| Antigravity | локальный языковой сервер Antigravity — тот же запрос, что делает панель расхода в самой IDE |

Если Antigravity не запущен, виджет корректно ожидает запуска языкового сервера.

## Установка

Скачайте `Tokpaek-Setup.exe` со страницы [релизов](https://github.com/Ilardar/Tokpaek/releases) и запустите. Установка идёт в профиль пользователя, права администратора не нужны.

При установке можно сразу включить автозапуск; позже это переключается в настройках или в меню трея.

## Как пользоваться

- **ЛКМ по кругу** — перетащить; **ЛКМ по плашке** — переключить таймер (ПЯТЬ ЧАСОВ / СЕМЬ ДНЕЙ).
- **Край круга** — изменить размер перетаскиванием.
- **ПКМ по виджету** — меню: Обновить, Домой (в левый верхний угол), Показывать поверх всех окон, Настройки, Закрыть.
- **Иконка в трее** — то же меню. Настройки открываются по центру того монитора, где вы находитесь.

## Требования

- Windows 10/11, x64.
- Запущенный инструмент Antigravity: Antigravity IDE, Antigravity 2.0 или CLI (квота живёт в его локальном языковом сервере).
